### 5.1. Карточка столика (bottom sheet)

При нажатии на стол открывается детальная карточка. Содержимое зависит от статуса:

**🔴 Занят (walk-in / посадка без брони в приложении)**

```
┌─────────────────────────────┐
│        Стол №3              │
│         [Занят]             │
├─────────────────────────────┤
│ Пришли в 18:45              │
│ Примерное освобождение —    │
│ через ~1–1,5 ч после посадки│
├─────────────────────────────┤
│ [🔔 Оповестить, когда       │
│     освободится]            │
│ [Закрыть]                   │
└─────────────────────────────┘
```

| CTA | Auth | Действие |
|-----|------|----------|
| Оповестить | 🔒 | → **Confirm Dialog** → Push, когда стол → FREE |
| Закрыть | 🔓 | Закрыть sheet |

**Confirm Dialog (оповещение):**

```
┌─────────────────────────────┐
│   Подтвердить оповещение    │

└─────────────────────────────┘
```

**После подтверждения (занят):**

```
│ ✓ Мы сообщим, когда стол    │
│   освободится               │
│ [Закрыть]                   │
```

**🟡 Забронирован**

```
┌─────────────────────────────┐
│        Стол №4              │
│      [Забронирован]         │
├─────────────────────────────┤
```

## 5.2. Confirm Modal (глобальный) 🔒

Переиспользуемый диалог подтверждения. Используется минимум в двух сценариях:

| Сценарий | Trigger | После «Подтвердить» |
|----------|---------|---------------------|
| Оповещение об освобождении | Карточка 🔴 стол → «Оповестить…» | Подписка `TableWatch`, toast, статус на карточке |
| «Я приду» | Карточка 🟡 стол → «Я приду» | `arrival_confirmed`, push hostess, статус на карточке |

| CTA | Действие |
|-----|----------|
| Подтвердить / Да, я приду | Выполнить действие, закрыть confirm, вернуться на карточку столика |
| Отмена | Закрыть confirm, вернуться на карточку столика без изменений |

**Auth:** если пользователь не авторизован → сначала Auth Modal → после входа → тот же Confirm Modal.

## 6. Reservation Flow 🔒

**Шаги (stepper):**

1. **Дата и время** — calendar + time slots  
2. **Гости** — stepper 1–12  
3. **Стол** — Floor Map (только 🟢)  
4. **Предзаказ?** — «Только бронь» / «Заказать блюда заранее»  
5. **Подтверждение** — summary + push opt-in  

```
┌─────────────────────────────┐
│ Подтверждение брони         │
│ Заведение · Стол · Время    │
├─────────────────────────────┤
│ [+ Заказать блюда заранее]  │
│ [Подтвердить бронь]         │
├─────────────────────────────┤
│ ℹ️ При заказе блюд заранее: │
│ когда вы придёте, еда уже   │
│ будет на столе или поступит │
│ вскоре после вашего прихода │
└─────────────────────────────┘
```

| Ветка | Переход |
|-------|---------|
| Только бронь | → Confirmation → Orders tab |
| + Предзаказ | → Menu → Cart → Payment choice → Confirmation |
