# FoodAssistant

Виртуальный инструмент для общепита: карта заведений, бронирование столиков, предзаказ, QR-сессия за столом, вызов официанта, AI-подбор мест, уведомления о столиках.

**Статус:** документация и прототип; реализация кода — в `../foodassistant/` (см. корень репозитория).

> **Общий вход в репозиторий:** [`../../README.md`](../../README.md)  
> **Инженерия / Docker / API:** [`../../docs/ENGINEERING.md`](../../docs/ENGINEERING.md)

## Реализованная логика (актуально)

### Навигация и вход
- Онбординг → **выбор города** → карта (пилот: Бельцы)
- Нижняя панель: **QR-ряд** + 4 вкладки; на экране сканера — только 4 вкладки
- Карта: название города слева, кнопка «Сменить город»

### Карта зала — карточка столика
- **🔴 Занят:** время посадки «Пришли в …» → «Оповестить когда освободится» → Auth → **Confirm** → push при FREE
- **🟡 Бронь:** время брони, обратный отсчёт, правила **1 ч / 15 мин** → «Я приду» → Auth → **Confirm** → push staff
- **🟢 Свободен:** бронирование
- **🔵 Ваш:** переход в сессию

### QR и сессия
- Скан → **выбор способа заказа** (в приложении / позвать официанта)
- **Waiter Initial** — первый вызов после QR (устный заказ)
- **Waiter Session** — вызов из активной сессии (причина: заказ / счёт / вопрос / другое)

### Алкоголь
- В ресторане (сессия) — заказ через app, **выдача** с проверкой документа staff (Legea 1100, art. 30)
- Предзаказ к брони — только после verify staff + флаг; **не считается продажей** до check-in
- Grant/revoke в staff-app и admin; audit log; **юридическая экспертиза обязательна** — см. `APP_LOGIC.md` §8.4

Подробности: [`APP_LOGIC.md` §5.3–5.5, §8.4](./APP_LOGIC.md), [`UX_SCREENS.md` §10, §13](./UX_SCREENS.md)

## Быстрый старт

### Диаграммы (draw.io / diagrams.net)

1. Откройте [diagrams.net](https://app.diagrams.net/)
2. **File → Open from → Device**
3. Выберите `diagrams/foodassistant.drawio`

В файле 4 вкладки:

| Вкладка | Содержание |
|---------|------------|
| **User Flow** / **Путь клиента** | Путь клиента от запуска до оплаты |
| **Screen Map** / **Карта экранов** | Навигация и связи между экранами |
| **State Machines** / **Состояния** | Состояния столика, заказа и брони |
| **Staff Flow** / **Персонал** | Потоки официанта, админа и onboarding |

### UX-прототип

```bash
open prototype/index.html
```

Или откройте файл в браузере. Кликабельные экраны, переключатель языка RU/EN/RO (демо).

## Принятые решения

- **Платформа:** mobile + web, единый backend
- **Auth:** обязателен для брони, заказа, оповещений и «Я приду»
- **Оплата:** in-app или в заведении
- **QR:** walk-in и check-in по брони
- **Персонал:** web-панель + waiter app
- **География:** Бельцы, Молдова (пилот)
- **Подбор:** фильтры + AI + праздничные подборки
- **Языки:** ru, en, ro
- **Правила посадки на бронь:** сессия с −60 мин, освобождение за −15 мин (настраивается рестораном)
