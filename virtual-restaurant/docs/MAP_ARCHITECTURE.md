# Бесплатная карта FoodAssistant

## Решение

FoodAssistant использует единый открытый картографический стек для сайта и Android:

| Канал | Рендер | Стиль и тайлы | Ключ |
|---|---|---|---|
| Сайт | MapLibre GL JS | OpenFreeMap Positron / OpenStreetMap | не нужен |
| Android | MapLibre Native через `maplibre_gl` | тот же OpenFreeMap style URL | не нужен |

Тайлы и стиль карты всегда OpenFreeMap / MapLibre. Google Maps tiles не используются.

## Каталог точек на карте

Точки на карте — гибридный каталог, а не только опубликованные заведения из CRM:

| Источник | Что даёт |
|---|---|
| Google Places (Nearby, food types) | Рестораны, кафе и прочие food-точки вокруг центра города |
| FoodAssistant store | Опубликованные партнёры с координатами, рейтингом, свободными столами |

Backend объединяет оба источника в один список через **`GET /api/v1/map/places`** (по умолчанию `city_id=city-balti`). Ключ Google Places остаётся на сервере; браузер вызывает только наш API.

### Флаг `in_database`

Каждая точка в ответе содержит явное поле **`in_database`** (всегда присутствует в JSON):

- **`false`** (по умолчанию) — точка из Google, не связана с заведением FoodAssistant.
- **`true`** — партнёр FoodAssistant: либо совпадение по `google_place_id`, либо заведение только в нашей БД (Google его не вернул).

Сопоставление в v1 — только exact match по `google_place_id`. Для `in_database: true` доступны операционные поля (`venue_id`, `free_tables`, бронирование). Для Google-only точек — нейтральный пин и «скоро в FoodAssistant», без кнопки брони.

Если Google недоступен или отключён, endpoint возвращает только DB-заведения с `in_database: true` и не ломает карту.

### Будущее (вне текущего scope)

Просмотр меню для любого `google_place_id`, в том числе для точек с `in_database: false`, планируется отдельно; сейчас меню только у партнёров в базе.

## Возможности

- настоящие улицы и здания Бельц;
- масштабирование и перемещение карты;
- автоматическое приближение ко всем точкам каталога;
- два стиля маркеров: партнёры FoodAssistant (`in_database: true`) и прочие food-точки;
- количество свободных столов на web-маркере для партнёров;
- группировка близких точек на сайте;
- выбор точки синхронизирован с карточкой / панелью;
- резервный интерфейс при сетевой ошибке;
- обязательная атрибуция OpenStreetMap/OpenFreeMap.

## Масштабирование

Публичный OpenFreeMap подходит для разработки, пилота и запуска без бюджета на карты. У него нет API-ключей и лимита просмотров, но также нет SLA. При росте нагрузки FoodAssistant может самостоятельно разместить OpenFreeMap/PMTiles и заменить только style URL. Компоненты сайта, Android и endpoint `map/places` при этом останутся прежними.

Квота Google Places контролируется на backend (радиус, лимит результатов, graceful fallback на DB-only).
