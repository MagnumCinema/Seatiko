# Бесплатная карта FoodAssistant

## Решение

FoodAssistant использует единый открытый картографический стек для сайта и Android:

| Канал | Рендер | Стиль и тайлы | Ключ |
|---|---|---|---|
| Сайт | MapLibre GL JS | OpenFreeMap Positron / OpenStreetMap | не нужен |
| Android | MapLibre Native через `maplibre_gl` | тот же OpenFreeMap style URL | не нужен |

Рестораны не берутся из стороннего каталога. Backend FoodAssistant отдаёт опубликованные заведения с координатами, рейтингом и количеством свободных столов. Поэтому модерация и CRM управляют тем, какие точки появляются на карте.

## Возможности

- настоящие улицы и здания Бельц;
- масштабирование и перемещение карты;
- автоматическое приближение ко всем опубликованным ресторанам;
- фирменные зелёные и оранжевые точки FoodAssistant;
- количество свободных столов на web-маркере;
- группировка близких точек на сайте;
- выбор точки синхронизирован с карточкой ресторана;
- резервный интерфейс при сетевой ошибке;
- обязательная атрибуция OpenStreetMap/OpenFreeMap.

## Масштабирование

Публичный OpenFreeMap подходит для разработки, пилота и запуска без бюджета на карты. У него нет API-ключей и лимита просмотров, но также нет SLA. При росте нагрузки FoodAssistant может самостоятельно разместить OpenFreeMap/PMTiles и заменить только style URL. Компоненты сайта, Android и данные ресторанов при этом останутся прежними.
