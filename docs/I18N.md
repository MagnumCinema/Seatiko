# FoodAssistant — локализация (i18n)

Поддерживаемые языки: **RU** · **EN** · **RO**

---

## 1. Стратегия

| Аспект | Решение |
|--------|---------|
| Fallback | `en` — если перевод отсутствует |
| Default при первом запуске | Язык системы → если не ru/en/ro → `en` |
| Переключение | Профиль → Язык; сохраняется в аккаунте и localStorage |
| Контент ресторанов | Меню и описания — мультиязычные поля в CMS ресторана |
| AI-чат | Ответы на языке интерфейса пользователя |
| Форматы | Дата/время/валюта — locale-aware (Intl API) |
| RTL | Не требуется для MVP |

---

## 2. Определение языка при запуске

```
[Запуск]
    │
    ├─► Сохранённый выбор пользователя? → использовать
    │
    ├─► Язык ОС ∈ {ru, en, ro}? → использовать
    │
    └─► Иначе → en
```

На splash можно показать ненавязчивый баннер: «Language / Limba / Язык» если ОС не совпала с геолокацией (опционально, фаза 2).

## 3. Namespace-структура ключей

```
common.*          — кнопки, ошибки, загрузка
nav.*             — табы нижней панели
onboarding.*      — слайды первого запуска
map.*             — карта города, фильтры, поиск
venue.*           — карточка заведения
floor.*           — карта зала, статусы столиков
reservation.*     — бронирование
menu.*            — меню, корзина
order.*           — статусы заказа
session.*         — экран «Ваш стол»
waiter.*          — вызов официанта
payment.*         — оплата
discover.*        — AI, подборки, праздники
auth.*            — вход, регистрация
confirm.*         — глобальные подтверждения (notify, «Я приду»)
alcohol.*         — ограничения алкоголя, подсказки
profile.*         — профиль, настройки
staff.*           — интерфейс персонала (отдельный bundle)
```

## 5. Контент ресторанов

Каждое заведение в CMS заполняет:

```json
{
  "name": { "ru": "...", "en": "...", "ro": "..." },
  "description": { "ru": "...", "en": "...", "ro": "..." },
  "menu": {
    "categories": [{
      "name": { "ru": "...", "en": "...", "ro": "..." },
      "items": [{
        "name": { "ru": "...", "en": "...", "ro": "..." },
        "description": { "ru": "...", "en": "...", "ro": "..." }
      }]
    }]
  }
}
```

Если перевод отсутствует — показывается `en`, затем первый доступный.

## 6. Техническая реализация (будущее)

- **Frontend:** `i18next` + JSON-файлы `/locales/{ru,en,ro}.json`
- **Backend:** `Accept-Language` header для API-ошибок и push-уведомлений
- **AI:** system prompt включает `user_locale: ru|en|ro`
- **QA:** чеклист — все экраны на 3 языках, нет overflow в кнопках RO (длинные строки)
